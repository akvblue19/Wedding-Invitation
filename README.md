# Ankit Weds Gautami — The Celebration

A responsive, illustrated wedding invitation built with plain HTML, CSS, and JavaScript.

Open `index.html` directly in a browser, or serve this folder with any static file server. Original wedding illustrations are kept as separate, optimized JPEG assets in `public/images/`.

The invitation includes an India Standard Time wedding countdown, mobile navigation, event detail cards, and an RSVP form that saves replies in the current browser's local storage. There is no server-side RSVP service configured.
